Le Constat

The Challenge

Dans de nombreuses institutions de référence, la production de documents cartographiques officiels reste dépendante de logiciels propriétaires coûteux et de processus manuels. La génération d'un seul document peut prendre plusieurs heures, mobilisant des agents sur des tâches répétitives à faible valeur ajoutée.

In many reference institutions, the production of official cartographic documents remains dependent on expensive proprietary software and manual processes. Generating a single document can take several hours, tying up staff on repetitive, low-value tasks.

L'Architecture

The Architecture

J'ai conçu un prototype d'API REST sécurisée (FastAPI) couplé à un géoportail interactif (Leaflet). Le système lit automatiquement le raster approprié parmi un patrimoine de 176 fichiers, calcule les emprises géodésiques (UTM 32N/33N, Clarke 1880), et génère un PDF officiel avec description légale et QR code de vérification.

I designed a secure REST API prototype (FastAPI) coupled with an interactive geoportal (Leaflet). The system automatically reads the appropriate raster from a repository of 176 files, calculates geodesic extents (UTM 32N/33N, Clarke 1880), and generates an official PDF with legal description and verification QR code.
